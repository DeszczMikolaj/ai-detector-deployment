## Etap IV — projekt prototypu

Określa, które wymagania ze specyfikacji etapu III realizuje prototyp, przypadki użycia prototypu oraz projekt wysokiego poziomu i projekty części: frontend (rozdz. 5), backend i infrastruktura (rozdz. 6), baza danych i pipeline douczania (rozdz. 7). Rozdział 8 zawiera decyzje U-01…U-34 i jawne zmiany kryteriów względem specyfikacji etapu III (WF-A-06, WN-17).

Dokument powołuje się na ADR z [`docs/adr/`](../adr/README.md). Propozycje ADR wymienione w rozdz. 8 (m.in. ADR-0018…0024) trafiają do repozytorium osobnymi PR-ami; do tego czasu źródłem ich treści jest ten dokument.

Źródła LaTeX dokumentu są w projekcie Overleaf zespołu.
